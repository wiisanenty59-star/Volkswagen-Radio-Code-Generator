# VAG Radio Code Generator

Lost your Volkswagen, Audi, Škoda, or SEAT radio code?  
Enter your radio's serial number to instantly generate the correct unlock PIN for supported models.

---

## 🚗 Supported Brands

- Volkswagen
- Audi
- Škoda
- SEAT

---

## ⚡ Features

- Instant radio code calculation
- Supports multiple legacy radio models
- Simple and user-friendly
- Step-by-step unlock instructions
- Helps prevent permanent radio lockouts

---

## 🔢 How It Works

1. Locate the 14-character serial number on your radio unit  
   Example: VWZ1Z2E4993611
   2. Enter the serial number into the generator

3. Click **Generate Code**

4. Use the code to unlock your radio

---

## 📻 How to Enter Your Code

1. Turn on the radio  
Display should show `SAFE` then `1000`

2. Use preset button **1** to set the first digit (cycle 0–9)

3. Use preset buttons **2, 3, and 4** to set remaining digits

4. Press and hold the **AM/FM** or `>>` button until you hear a beep
